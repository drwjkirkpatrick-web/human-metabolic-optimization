## Part 2: Clinical Presentations

**LHON (Leber hereditary optic neuropathy):**
| Feature | Characteristic |
|---------|---------------|
| Onset | Acute/subacute central vision loss in young adult males |
| Penetrance | ~50% of males, ~10% of females with primary mutations |
| Triggers | Tobacco, alcohol, cyanide exposure, head trauma, antiretrovirals |
| Prevention | Absolute smoking/alcohol avoidance in at-risk maternal relatives |
| Treatment | Idebenone 900 mg/day (approved in EU); EPI-743 (experimental) |
| Prognosis | m.14484T>C > m.11778G>A > m.3460G>A for recovery |

**MELAS (Mitochondrial Encephalomyopathy, Lactic Acidosis, Stroke-like episodes):**
| Feature | Characteristic |
|---------|---------------|
| Mutation | m.3243A>G (tRNA Leu) most common |
| Onset | childhood to young adulthood |
| Stroke-like episodes | Occipital cortex, reversible with arginine |
| Lactic acidosis | Elevated lactate/pyruvate |
| Management | **Arginine 0.3 g/kg IV during stroke-like episodes** |
| | CoQ10, L-carnitine, alpha-lipoic acid, B vitamins |
| | Avoid valproate, metformin, linezolid |

**MCAD (Medium-chain acyl-CoA dehydrogenase) deficiency:**
| Feature | Characteristic |
|---------|---------------|
| Incidence | 1:15,000 births (most common FAOD) |
| Crisis trigger | Fasting > 12 hours, illness, excessive exercise |
| Presentation | Hypoketotic hypoglycemia, vomiting, lethargy, seizures |
| Screening | Newborn screening (C8 acylcarnitine) catches ~95% |
| Management | **Never fast > 10-12 hours**; illness protocol with glucose |
| | Add L-carnitine, riboflavin; medium-chain fat restriction |

## Part 3: Mitochondrial Support Protocol

**Universal mitochondrial cofactors (all genotypes):**
- [ ] **CoQ10 (ubiquinol)** → 100-300 mg/day ( Complex III shuttle member)
- [ ] **L-Carnitine** → 500-2000 mg/day (acylcarnitine shuttle for FA transport)
- [ ] **Alpha-lipoic acid** → 300-600 mg/day (PDH, KGDH cofactor; antioxidant)
- [ ] **B vitamins (B1, B2, B3, B5)** → PDH, KGDH, succinate dehydrogenase cofactors
- [ ] **Magnesium** → required for ATP synthesis (ATP-Mg complex)
- [ ] **Creatine monohydrate** → 3-5 g/day (phosphocreatine shuttle)
- [ ] **PQQ** → 10-20 mg/day (mitochondrial biogenesis)
- [ ] **NAD+ precursors** → NMN 250-500 mg or NR 300-500 mg (Complex I substrate)

**Avoid in mitochondrial disease:**
- [ ] **Metformin** → inhibits Complex I (especially dangerous in ND mutations)
- [ ] **Valproate** → inhibits CPT1A and mitochondrial function
- [ ] **Linezolid** → inhibits mitochondrial ribosomes (mimics aminoglycoside toxicity)
- [ ] **High-dose aspirin** → Reye-like risk in children; depletes CoQ10 in adults
- [ ] **Statin myopathy** → secondary CoQ10 depletion → avoid or supplement aggressively

## Clinical Pearl
> The "three-generation rule" for mtDNA: all children of an affected mother inherit the mutation, but only some express disease. Fathers never transmit mtDNA. When counseling a patient with LHON, the first step is ALWAYS to trace the maternal line — ask about uncles with visual loss, maternal aunts with MS-like symptoms, or cousins with exercise intolerance. These may all be incomplete penetrance presentations of the same mitochondrial variant. Smoking in maternal male relatives is the single strongest modifiable risk factor for conversion from carrier to affected.
