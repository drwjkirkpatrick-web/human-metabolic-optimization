## Part 1: The GST Buffer Assessment

Check the patient's genotype for the following:
- [ ] **GSTM1 Status:** Present / Null
- [ ] **GSTT1 Status:** Present / Null

**Clinical Logic:**  
If BOTH are Null, the patient has a severely reduced Phase II buffer.

**Action:** Start with low-dose NAC + Selenium before moving to aggressive mobilization.

---

## Part 2: The "Toxin Load" Inventory

Identify current environmental exposures:
- [ ] Heavy Metals (Mercury, Lead, Arsenic)
- [ ] Chemical Solvents / VOCs / Pesticides
- [ ] High-Saturated Fat Diet / Advanced Glycation End-products (AGEs)
- [ ] Recreational drug use
- [ ] Prescription polypharmacy

**Exposure severity:** _Lite / Moderate / Heavy_

---

## Part 3: Support Protocol

Based on the above, select the priming cofactors:
- [ ] **NAC (N-Acetyl Cysteine)** → Supports glutathione substrate synthesis
- [ ] **Selenium** → Essential for GST peroxidase activity
- [ ] **Vitamin C** → Reduces oxidized glutathione (GSSG → GSH)
- [ ] **Alpha-Lipoic Acid** → Regenerates glutathione and chelates divalent metals
- [ ] **Glycine** → Rate-limiting amino acid for glutathione synthesis
- [ ] **Milk Thistle (Silymarin)** → hepatocellular membrane stabilization

**Dosing notes:** Start low (NAC 300 mg, Selenium 100-200 mcg) and titrate upward based on tolerance.

---

## Clinical Pearl
> GSTM1/GSTT1 Null status affects ~50% (GSTM1) and ~20% (GSTT1) of populations. In cancer patients, Null alleles confer higher risk from xenobiotic exposure but also predict better response to NAC-based priming.
